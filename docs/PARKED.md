## 已知限制（实现层面的取舍，不是失败）

### 1. OAuth2 类协议（Drive / OneDrive / Dropbox / GCS）

- **现象**：当前把 **OAuth2 access token 当作密码**填入站点管理器即可使用。
- **原因**：交互式授权（浏览器打开 + 本地回环回调 + PKCE + refresh token 续期）需要 UI 侧配合，
  而 UI 侧（`src/interface`）的授权弹窗不在"只做协议兼容"的范围内。
- **注意**：开源客户端不能内置 client_secret，必须用 public client + PKCE。

### 2. 分片/断点续传上传

- 目前上传都是"单请求流式上传"。S3 >5GB 的 multipart、Azure block blob 分块、
  Graph 上传会话尚未实现；下载侧已支持 `Range` 续传。

### 3. 对象存储语义降级

- `chmod`、递归删目录：对 S3 / B2 / Azure / GCS / Drive / OneDrive / Dropbox 一律返回
  `FZ_REPLY_NOTSUPPORTED`（对象存储没有 POSIX 权限与原子目录删除）。
- 目录用"占位对象"表示（S3/B2/Azure/GCS 用尾部 `/` 的零字节对象），
  因此某些第三方工具创建的"隐式目录"可能显示为空目录。
- Google Drive / 早期评估过的 Box 这类"id 语义"服务没有真实路径，
  目录是靠逐段 `name=` 查询解析出来的，重名时只取第一个匹配。
